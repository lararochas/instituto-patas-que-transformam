# Instituto Patas que Transformam

## Sobre o projeto

O Instituto Patas que Transformam é um projeto web desenvolvido para representar uma instituição voltada ao resgate, acolhimento e adoção responsável de animais.

A aplicação apresenta informações sobre o instituto, seus projetos e um formulário de cadastro com recursos de interatividade e persistência de dados.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Estrutura do projeto

```text
instituto-patas-que-transformam/
├── html/
├── css/
├── js/
│   └── modules/
└── imagens/
```

## Como executar localmente

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão Live Server.
4. Abra o projeto utilizando o Live Server.
5. Acesse a página inicial pelo navegador.

O uso de um servidor local é necessário para que os módulos JavaScript sejam carregados corretamente.

## Funcionalidades

* Navegação entre páginas.
* Renderização dinâmica com JavaScript.
* Máscaras para CPF, telefone e CEP.
* Validação de formulário.
* Persistência de dados com `localStorage`.
* Navegação por teclado no submenu.
* Interface responsiva.

## Versionamento

O projeto utiliza Git e GitHub para controle de versões.

Foi adotado um fluxo baseado no GitFlow, utilizando as branches `main`, `develop` e branches de funcionalidades.

As mensagens seguem o padrão Conventional Commits, utilizando tipos como `feat` para novas funcionalidades.

As alterações são integradas por meio de Pull Requests antes de chegarem à branch principal.

## Acessibilidade

Foram aplicadas práticas básicas de acessibilidade, incluindo navegação por teclado, uso de elementos semânticos, textos alternativos para imagens e indicadores visuais de foco.
